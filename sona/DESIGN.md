# SONA · 流声 — 设计与验收规格

> 配套文档:`TECH.md`(技术架构)、`ROADMAP.md`(实现路径)、
> `INTERACTIONS.md`(交互动效总规格——每条动效的触发/参数/中断/降级/验收)

用 UI 组件库从 0-1 构建的**生成式音乐播放器**,目标是生产级(可盈利
水平)的完成度;同时作为组件库的**验收测试**,覆盖其全部核心组件与
状态并产出 API 体验反馈。

产品主张:**你的歌单,甚至你的曲目,都由你创造。**
- 用户可创建/编辑/排序自己的歌单(持久化 + 导入导出)
- 声音工坊:选情绪、色相、时长与种子,实时试听并保存**属于自己的曲目**
- 视觉方向:封面即可视化——以曲目 hue 渐变为材质、实时频谱为生命的
  沉浸式正在播放页;明暗双主题;克制而丝滑的动效

## 与众不同的一点

音频是**真的**。每首曲目由 WebAudio 生成式引擎实时合成(种子化的和弦进行 +
五声音阶琶音 + 贝斯 + 氛围打击),播放/暂停/进度/音量/频谱全部真实工作,
零音频文件、零外部请求。

## 页面结构

1. **正在播放**(主视图)— 「重力歌词」沉浸页:
   - 背景:曲目 hue 渐变材质,按低频能量呼吸(Spotify Canvas 式)
   - **重力歌词**:每首曲目带时间戳诗行(`lyrics: [{t, line}]`);当前行
     由粒子聚合成字形(复用 GRAVITY ROOM 的文字采样 + 弹簧粒子技术),
     换行时粒子从上一行字形流变到下一行(文字变形);重低音命中时粒子
     受一次径向冲击波并弹回字形;上下行以小字号低透明度伴随
     (Apple Music 歌词页式层级)
   - 频段驱动:低频→冲击强度与封面脉动,中频→粒子风向漂移,
     高频→星尘微粒闪烁
   - 控制:进度 Slider、播放控制(上一首/播放暂停/下一首)、音量
     Slider、随机 Switch、循环三态 IconButton(off→all→one 循环切换)
   - 预算:粒子 ≤1200、DPR≤2、共享单 rAF、掉帧自动降密度;
     reduced-motion 下歌词为静态行 + 透明度高亮,无粒子
2. **曲库** — Tabs(歌单 / 专辑 / 歌手),曲目列表(行内播放状态、时长、
   悬停操作),搜索
3. **队列** — 显示实际播放顺序 playOrder;拖拽排序(随机关闭时同步
   编辑手动顺序);清空(确认 Modal)
4. **声音工坊** — 情绪/色相/时长(60-300s)/种子(规范化为非负整数,
   保存前展示)选择器,独立试听通道实时试听,命名保存为自己的曲目;
   「我的创作」支持**重命名与删除**(确认 Modal,删除级联见 TECH §4)
5. 底部**迷你播放条** — 全局常驻,点击展开正在播放

## 播放语义(行为契约)

**队列模型**:`sourceQueue`(手动顺序,拖拽排序的对象)与 `playOrder`
(实际播放顺序)为两个平行的条目 id 数组。随机关闭时二者相同;开启时
playOrder 为 sourceQueue 的种子化重排(当前曲置首),关闭时恢复
sourceQueue 并将索引对位到当前曲。

- 播放歌单 = **替换**整个队列(从被点击曲目起播)
- 「加入队列」= 追加到末尾(Toast 反馈);「下一首播放」= 插入当前曲之后
- 移除当前播放曲 → 自动切到 playOrder 的下一首;整个队列被清空(确认
  Modal)→ 停止播放,迷你条转空态
- 随机开启期间拖拽队列 = 编辑 playOrder 本身;sourceQueue 保持,供随机
  关闭时恢复

**next/prev 真值表**(E = 已在 playOrder 末尾):

| repeat | next(非 E) | next(E) | prev(已播 >3s) | prev(≤3s) |
| --- | --- | --- | --- | --- |
| off | 下一首 | 停止,停留末曲 | 回本曲 0s | 上一首;首曲则回 0s |
| all | 下一首 | 回 playOrder[0] | 同上 | 同上 |
| one | 下一首 | 回 playOrder[0] | 同上 | 同上 |

`repeat=one` 只作用于**自然播完**(onEnded 重播本曲);手动 next/prev
永远切曲——手动操作尊重用户意图。

## 组件库验收覆盖表

| 组件 | 使用场景 | 验证的状态 |
| --- | --- | --- |
| Button(变体/尺寸) | 播放控制、Modal 操作 | default/hover/press/disabled |
| IconButton | 上下曲、循环(三态循环切换)、收藏 | 状态循环/active 切换 |
| Slider | 进度条、音量 | 拖拽中/跳转/禁用(直播) |
| Switch/Toggle | 随机播放 | on/off/切换动画 |
| Tabs | 曲库分区 | 切换指示器动画 |
| Card | 歌单封面卡 | hover 抬升 |
| List/ListItem | 曲目列表、队列 | 播放中高亮/悬停操作显隐 |
| Modal | 清空队列确认、添加到歌单 | 焦点管理/Esc/遮罩点击 |
| Toast | 收藏/加入队列反馈 | 入场/自动消失 |
| Dropdown | 曲目行「更多」菜单 | 定位/键盘导航 |
| Skeleton | 曲库首次加载 | shimmer |
| Badge/Avatar | 歌手头像、正在播放标记 | — |
| Input | 歌单命名/描述、工坊曲目命名、搜索 | focus/错误态(空名) |

验收产出:`FEEDBACK.md` — 组件 API 不顺手/缺失/文档不符的清单。

## 技术分层(kit 无关层已先行实现)

- `data.js` — 曲库数据(ES module):歌单/曲目/种子/色相
- `audio.js` — 生成式音频引擎(ES module,框架无关):
  `createEngine()` → load/play/pause/seek/setVolume/getTime/analyser/onEnded
- UI 层 — 等组件库落地后用其组件实现(技术栈跟随组件库)
