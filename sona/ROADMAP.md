## M0 · 基座 ✅

**交付物**:`audio.js` 生成式引擎、`data.js` 官方曲库、`DESIGN.md`
**验收**(已通过):无头频谱验证——真实出声、计时精确、暂停冻结、
跳转稳定、自然结束回调、切歌续播,零控制台错误

## M1 · UI 装配 ⏳(依赖:组件库分支落地,轮询中)

**交付物**:正在播放 / 曲库(Tabs)/ 队列三视图 + 全局迷你播放条,
全部使用组件库组件;频谱驱动的封面可视化
**验收**:
- 组件覆盖表(DESIGN.md)中每个组件至少一处真实使用
- 播放状态在迷你条 / 正在播放 / 列表行三处永远一致
- Playwright:播放→暂停→跳转→切歌→队列播放全链路零报错
- **播放语义真值表逐格断言**(DESIGN.md「播放语义」):next/prev ×
  repeat 三态 × 队列末尾;repeat=one 自然播完重播本曲、手动切曲切走
- 随机开→记录后 3 首→刷新→断言顺序一致;随机关→恢复手动顺序且
  当前曲索引对位

## M2 · 用户歌单(用户输入)⬜

**交付物**:歌单 CRUD——新建(命名+描述+封面色相)、重命名、删除
(确认 Modal)、添加/移除曲目(Dropdown + Toast)、拖拽排序;
localStorage 持久化(schema v1);JSON 导入/导出
**验收**:
- 刷新页面后歌单完整恢复;隐私模式写入失败有明确 Toast
- 导入非法 JSON:逐条校验、跳过并汇报,不崩溃;**含冲突 id 的合并
  导入**:歌单内引用随 oldId→newId 映射保持有效
- E2E:建歌单→加 5 曲→排序→删 1 曲→**最后一次改动后立即刷新
  (无人为等待)**→校验顺序与内容
- 免费层第 3 个歌单创建被拦截并展示升级引导(flags.js 随 M2 交付)

## M3 · 声音工坊(产品壁垒)⬜

**交付物**:自定义曲目生成器——用户选情绪(calm/bright/drive)、
色相、时长(60-300s),随机或手动种子(规范化展示),经**独立试听
通道**实时试听后命名保存;产物进入曲库「我的创作」Tab,可加入任意
歌单,支持**重命名与删除**(删除级联清理歌单/队列引用,见 TECH §4)
**验收**:
- 同一种子、两个**全新引擎实例**输出频谱快照一致(调度级确定性,
  见 TECH §5;噪声缓冲已种子化)
- 试听后取消:恢复原队列/索引/播放进度;试听中刷新不残留未保存
  曲目的任何引用
- 试听与保存后播放频谱非静音;自定义曲目参与队列/歌单全流程
- 免费层上限 3 首:触顶展示升级引导;**造 3 → 删 1 → 再造成功**
- E2E:建曲→加入歌单+队列→删曲→刷新→歌单/队列/当前曲状态干净

## M4 · 重力歌词与美观打磨 ⬜

**交付物**:
- **重力歌词播放页**(产品级卖点):曲目诗行数据(12 首 × 6-10 行,
  含时间戳);粒子字形聚合/行间流变/低频冲击波(复用 GRAVITY ROOM
  文字采样与弹簧粒子技术);频段驱动背景(低频呼吸/中频风向/高频
  星尘);节拍脉动
- 视觉终稿:明暗双主题精修、页面间转场、微交互、空状态设计
**验收**:
- 粒子 ≤1200、共享单 rAF,播放中稳定 60fps(掉帧自动降密度)
- 歌词行切换与音频时间同步误差 < 200ms;seek 后当前行立即校正
- 低频冲击波仅在真实节拍能量峰触发(静音段零触发,E2E 断言)
- reduced-motion:静态歌词 + 透明度高亮完整可用
- 独立视觉审查通过;双主题截图无对比度/对齐缺陷
